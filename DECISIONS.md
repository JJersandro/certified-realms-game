# Flame Game — Decision Register

## D-001 — Roadmap is the continuity anchor
**Status:** Locked

The roadmap is not replaced by implementation-tool preferences. Tooling may change while the project direction remains stable.

## D-002 — Base44 is reference material
**Status:** Locked

The Base44 prototype is already reference material. It may be mined for useful behavior, mechanics, wording, structure, and visual ideas. It is not a required export source or runtime dependency.

## D-003 — Certified Realms is game data
**Status:** Locked

Certified Realms source material is treated as canonical game data and must be normalized into explicit, versionable structures.

## D-004 — Deterministic core before AI authority
**Status:** Locked

Authoritative game state, rules, scoring, combat, progression, and validation must be deterministic and testable. AI providers operate behind interfaces and cannot silently define authoritative state.

## D-005 — Claude Code is implementation agent
**Status:** Locked

Claude Code performs repository implementation, testing, debugging, and technical execution. It does not redefine product direction silently.
