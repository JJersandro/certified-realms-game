# Certified Realms — Canonical Data Contract

Certified Realms is game data, not decorative lore.

## Source status
The supplied Certified Realms material is the source to normalize into repository data. Any source image/document not yet committed remains **PENDING SOURCE ASSET**.

## Rules
- Do not invent missing canonical facts.
- Preserve source terminology where it is intentional.
- Separate source facts from implementation metadata.
- Every normalized entity should have a stable ID.
- Keep relationships explicit rather than burying them in prompts.
- Generated AI content must not become canon automatically.

## Initial data domains
- Realms
- Characters
- Enemies
- Allies
- Abilities / traits
- Certifications / knowledge domains
- Encounters
- Missions
- Rewards
- Progression / unlocks
- Questions / question metadata
- Narrative beats

## Normalization target
Source material → normalized JSON/data modules → deterministic game systems → presentation/AI content.

The exact schema is to be established during Phase 2 after the complete source material is available. Do not fabricate the final schema from incomplete screenshots.
